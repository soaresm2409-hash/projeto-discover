# DevLinks - @emma.magalhaes

O DevLinks é um agregador de links para usar como cartão de visitas online, construído durante a trilha Discover da Rocketseat.

## 🚀 Tecnologias

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

- HTML
- CSS
- JavaScript
- [Figma](https://www.figma.com/) para o protótipo do design.

## 💻 Projeto

O DevLinks permite centralizar as tuas principais redes sociais e links importantes numa única página responsiva, com a funcionalidade de alternar entre o tema claro (Light Mode) e escuro (Dark Mode).
